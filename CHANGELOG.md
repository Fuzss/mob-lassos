# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.2.1-mc26.2.x] - 2026-07-23

### Changed

- Lasso types now use mob categories for determining which mobs can be captured
- Furthermore, any behavior can be fully customized using entity type tags
- Mobs from lassos can now be released directly on water like using a spawn egg
- The mob holding timer no longer ticks down in creative mode

## [v26.2.0-mc26.2.x] - 2026-06-19

### Changed

- Update to Minecraft 26.2.x
